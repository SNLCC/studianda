# 使用须知与隐私说明

> 适用应用版本：勘读 Studianda 0.1.x　|　文档版本：v1.10　|　生效日期：2026-11-11

勘读（Studianda）是一个在你本机运行的学术阅读工具。这份说明讲清三件事：你的数据放在哪里、哪些内容会在什么情况下离开本机、以及使用中需要注意的风险。请在使用前通读；继续使用即表示你已阅读并理解本说明。

## 1. 当前定位

- **本地优先的阅读工具**：应用在你自己的电脑上运行，负责导入文献、组织阅读。
- **本工具不提供 AI 模型或生成能力**：本工具是本地阅读工具；AI 功能由你自行配置的第三方模型服务或本机模型提供。项目方不持有模型、不代收模型费用、不运营云端服务。
- **项目方不运营云服务、不保存你的密钥、不收集或回传你的资料与会话内容**：应用没有账号体系、没有云同步、没有遥测或崩溃上报；文献、笔记、会话记录与检索缓存都写在你选定的资料目录。但你使用会话、翻译、搜索等功能时，相应内容会发给你配置的第三方服务（见 §5），由该服务按其条款处理。
- **生成内容的合规性与标识义务由对应 AI 服务提供者承担**：本工具只负责接入、展示与标识提示，不替代模型服务方的备案、审核、内容处置与投诉等义务。

## 2. 三方角色

| 角色 | 是谁 | 承担什么 |
| --- | --- | --- |
| 工具提供方 | 勘读 Studianda 项目 | 提供软件本身；不提供 AI 模型或生成能力；软件只在你本机读取和处理 |
| 模型服务提供者 | 你选择的模型平台；若你自己在本机运行模型，则提供者是你本人 | 提供并运营模型服务，按其与你之间的协议处理你发送的内容 |
| 使用者 | 你 | 自行申请并合法持有密钥、遵守第三方服务条款、对导入内容的合法性负责 |

## 3. 密钥与 BYOK 边界

应用采用**自带密钥**（BYOK，Bring Your Own Key）：不内置任何生成式 AI 模型，也不内置任何模型/搜索服务的密钥，不提供免费额度。安装后没有预置的模型连接；需要你在设置中自行配置并指定用途。本机 OCR 使用开源 `tesseract.js` 识别引擎（OCR，不是生成式 AI），语言训练数据不随包分发、按需下载。

- 你需要**自行向模型服务商申请密钥**并**合法持有**。通常由你与厂商签约；如果你使用机构提供的 Key，签约方可能是机构、他人或账号持有人。服务条款、计费方式、数据处理与内容政策由该协议决定。
- **共享密钥、机构密钥或他人账号**：签约方可能是机构或他人；这不改变第三方服务条款，你仍受该厂商协议约束，密钥持有人对使用负最终责任。
- **仅接入合规服务**：请仅接入依法合规运营的生成式 AI 服务；请勿接入未备案/未合规服务、来源不明的共享 Key 或中转端点，相关数据传输风险与合规责任由你自行承担。应用不验证服务商是否已备案。
- **机构用户**：当前暂不接受机构用户。
- **密钥位置**：你在设置里保存的密钥（模型服务、语音、联网搜索、Zotero、在线解析）经 Electron `safeStorage` 加密后写入独立文件 `userData/secrets.json`（Windows 通常为 `%APPDATA%\Studianda\secrets.json`），**不写入资料目录，也不随资料备份**；更换资料目录或卸载程序也不会带走密钥。
- **传输方式**：远程端点只允许 HTTPS；HTTP 仅允许本机或局域网地址。项目方不运营中转/代理服务器，请求由客户端发往你配置的端点；发往该端点的内容见 §5（包括问题、所选原文、笔记/批注和系统提示词等）。**不建议使用第三方中转/代理**：请优先使用模型厂商官方端点或本机模型；第三方中转的合法性取决于运营者资质、备案、数据出境与厂商条款，不能一概而论，使用风险由你自行承担。
- **不要**把密钥贴在 issue、日志、截图或分享的资料目录里；如误泄露，请立即到对应平台轮换。

## 4. 数据放在哪、保留多久

- **资料目录**：首次启动由你选择。文献 PDF 副本、SQLite 数据库、批注、笔记、译文、会话记录、检索缓存与备份都写在这里；卸载程序不会删除资料目录。
- **未加密**：资料目录、备份与诊断包都未加密。敏感资料请自行加密磁盘、隔离系统账户，或在使用结束后删除资料目录。
- **删除与残留**：删除文献会级联清理它的批注、笔记、会话消息、译文与索引；「设置 → 数据与维护 → 清空全部本地数据」（二次确认）会删除文献、批注、笔记、会话记录、译文、检索缓存、备份、诊断包与本地运行日志，**保留模型配置与密钥**；数据库随后做 WAL 截断与 VACUUM 以减少残留。但备份与回滚目录仍可能保留旧副本，不保证物理擦除。需要彻底删除时：先清空本地数据，再退出应用并删除整个资料目录（含 `backups/`、`diagnostics/` 等子目录）与用户数据目录中的日志。
- **导出与标识**：笔记与批注可导出为 Markdown 或带批注的 PDF 副本，导出后的文件由你自行保管，不受应用控制。Markdown 文件头会写显式 AI 提示、学术披露提示与隐式注释。
- **诊断包**：生成诊断包时会做脱敏，不含 PDF 原文、正文或密钥；但请自行检查后再决定是否分享。

## 5. 逐功能数据流向

下表列出**所有会把内容发离本机的功能**。"默认状态"指全新安装、未做任何配置时的行为。除下表所列，应用不向任何第三方发送数据。

| 功能 | 发给谁 | 发送什么 | 何时发送 | 默认状态 |
| --- | --- | --- | --- | --- |
| 会话 / 精读 / 翻译 / 摘要 | 你在设置中配置的会话模型端点 | 问题、检索命中片段或所选页面/章节原文、勾选的笔记与批注正文，以及系统提示词/指令等；**不含 PDF 原件** | 你配置模型并提问、翻译或摘要时 | 未配置，不外发 |
| 视觉读页 | 同上（需选用支持图像的模型） | 该页渲染成的单张 PNG 图片 | 你使用视觉读页模式时 | 默认不启用 |
| 向量（Embedding）/ 重排 | 你在设置中配置的 embedding 或重排端点 | 需要向量化或重排的检索文本、候选片段 | 你把这两项配置为远程模型时 | 默认本机 TF-IDF 与本地重排规则 |
| 在线解析 | MinerU 官方服务，或你填写的自定义 `/parse` 服务 | 单页 PDF（MinerU 精准/轻量），或页面 PNG（自定义解析） | 你选择在线解析、且已允许远程解析时 | 默认本机 Tesseract OCR；远程解析需你先允许 |
| 联网搜索 | DeepSeek Search API 或 Tavily | **脱敏后的搜索词**（DeepSeek ≤128 字符 / Tavily ≤500 字符） | 你点击「联网搜索」且权限允许时 | 无密钥不可用；权限默认「每次询问」 |
| 搜索规划 | 你配置的会话模型（仅在你选择把内容交给模型规划时） | 按「搜索规划隐私策略」发送当前问题，或按勾选范围整理出的问题/选文/历史回答/笔记/批注；**不是**原样转发整篇文献 | 发起联网搜索前的规划阶段 | 策略默认「仅提取关键词」：本地规则提取搜索词，**不调用模型、不外发** |
| 语音（ASR/TTS） | 你配置的模型或自定义语音服务端点 | 录音音频，或待朗读的文字 | 仅在模式选为「模型 / 自定义」时 | 默认使用本机系统语音组件（Windows `System.Speech`） |
| Zotero 与 WebDAV | 本机 Zotero（默认）、`api.zotero.org`（云端）、你填写的 WebDAV 地址 | 连接信息、文献条目与附件请求 | 你导入或同步 Zotero 时 | 默认本机模式 |
| OCR 语言包下载 | `raw.githubusercontent.com` / GitHub API | **只下载**语言模型文件，不上传文献 | 你在设置中点击下载时 | 默认未下载 |
| 更新检查 | GitHub Releases（`electron-updater`） | 版本号等更新所需元数据；不含文献、笔记、批注或会话内容 | 开启后，安装版启动约 10 秒后 | **默认关闭**；可在「设置 → 关于与更新」开启；开启后可设置环境变量 `STUDIANDA_DISABLE_UPDATE_CHECK=1` 强制关闭 |

**其他联网行为**：无遥测、无账号登录、无云同步、无公开 API/SDK、无内置密钥；本机服务只监听 `127.0.0.1`。

> AI 标识：回答区、译文区与 OCR/视觉结果旁有显式提示；「复制回答」「复制译文」与 OCR 文本复制会自动附带标识文字；存为笔记与导出 Markdown 会在**文件头**强制写入显式声明、学术披露提示与隐式注释，并**没有“一键去除”标识的开关**（导出文件可被手动编辑，但应用不提供去标识开关或批处理去标识能力）。请勿删除、篡改、伪造或隐匿这些标识。

## 6. 联网搜索与检索规划

- 联网搜索**默认不可用**：需要你先在设置中配置搜索平台密钥。
- **检索规划默认不调用模型**：发起搜索前，应用要先整理"到底要搜什么"。默认策略是「仅提取关键词」，只用本机规则从你允许的文本里提取搜索词，**不把内容发给任何模型**。
- **只有你主动选择时才把内容交给模型**：把「搜索规划隐私策略」改为「只把当前问题交给会话模型判断是否需要搜索」，或「按下方范围发送内容给会话模型」（并勾选来源：当前问题、最近提问与回答、选中原文、笔记、批注等）后，规划阶段才会把这些内容发给你配置的会话模型，由它生成最多 3 个搜索词。规划结果只用于生成搜索词，不直接作为回答内容。
- 你也可以取消勾选「允许当前会话模型规划搜索」，彻底不用模型规划。
- 搜索词会做**基础脱敏**（移除网址、邮箱与连续 6 位以上数字），但这不等于匿名；搜索平台仍会看到你的请求与查询词。
- **风险**：一旦选择"交给模型规划"，发送就发生在你最终确认搜索之前。如果你对问题本身也敏感，请保持默认的「仅提取关键词」。

## 7. 风险提示

1. **AI 生成内容可能不准确**：回答、译文、摘要都由模型生成，可能出错、编造或遗漏。引用可点击回原文页，但"有引用"不等于"已核实/真实准确"；重要判断请自行回到原文核对。
2. **未加密**：资料目录、备份与诊断包都不加密，见 §4。
3. **数据出境**：如果你选择境外模型端点或境外搜索、解析服务，相关内容会发送至境外，可能构成数据出境；是否需要取得授权、是否满足你所在机构或地区的要求，需要你自行判断。
4. **第三方服务中断与变更**：模型与搜索服务的可用性、价格与条款由厂商决定，可能随时变更或中断；本工具不能替厂商给出稳定服务承诺。
5. **备份残留与回滚**：备份、回滚目录与旧副本可能在你删除内容后仍然保留旧版本，见 §4。
6. **更新检查**：自动检查默认关闭，可在「设置 → 关于与更新」开启；开启后可设置环境变量 `STUDIANDA_DISABLE_UPDATE_CHECK=1` 强制关闭。安装包未做代码签名，Windows 可能提示「未知发布者」。
7. **请勿删除 AI 标识**：对于来自第三方或由本工具产生的 AI 生成标识与元数据，请勿删除、篡改、伪造或隐匿；本工具不提供去标识功能。
8. **不建议第三方中转/代理**：第三方中转/代理的合法性取决于运营者资质、备案、数据出境与模型厂商条款，不能一概而论；请优先使用模型厂商官方端点或本机模型，使用第三方中转的风险由你自行承担。

## 8. 适用人群与未成年人

- **面向成年专业用户**：本工具面向具备独立判断能力的研究者、教师、学生与写作者。用途是个人学习中的文献阅读、翻译、批注、笔记和会话辅助；不用于对外提供生成式 AI 服务，也不用于医疗、法律、金融等专业结论。
- **不面向未成年人**：应用不面向未成年人提供服务与推广，不进入校园渠道，也不设面向未成年人的功能或监护人模式。首次启动要求先打开并阅读当前版本《使用须知与隐私说明》，勾选「已查看使用须知与隐私说明」，并确认"已年满 18 周岁，并知悉本工具不面向未成年人"，之后才能开始使用。**未满 18 周岁请勿使用。**
- **请勿对外提供服务**：请勿将本工具用于对外提供咨询、内容生成或其他生成式 AI 服务；如违反，使用者自行承担相应责任。

## 9. 违法内容与违法使用

本工具是本地客户端，没有服务端内容审核链路，也**不能替代**在线服务提供者的审核、处置与报告义务。应用在系统提示词中要求模型拒绝生成违法有害内容，但这只是提示词层的约束，不等于内容审核或过滤。我们期望并建议你：

1. **不生成、不传播违法有害内容**；不利用本工具规避监管、伪造证据或侵犯他人合法权利。
2. 发现模型服务返回违法或明显不当内容时：立即停止该轮生成（界面提供「停止生成」），删除相关会话或笔记。
