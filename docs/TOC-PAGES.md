# 按「目录页」生成本地目录

在阅读器目录面板里填「目录页范围」（如 `3-5`），先**识别预览**（标题 + 印刷页码 +
自动对齐 PDF 物理页码），确认后生成导航；也可以随时清除设置回到 PDF 书签/标题规则。

## 1. 为什么

很多书的 PDF 没有书签目录，但正文前印了一张目录页。按标题字号/版式规则从几百页里猜章节，
既慢又容易漏（正文标题层级不统一、书前有版权页/序言）。直接解析这张目录页更省事：
标题与页码都是作者印好的，且天然带层级。

## 2. 怎么用（阅读器）

阅读器左侧「导航 → 目录」面板：

- **展示优先级**：PDF 有内置书签目录时默认显示内置目录；没有内置目录时显示本地目录。
  两者都有时，面板顶部出现「PDF 内置目录 / 本地目录」页签可切换；
- **列表**：每条显示「第 N 页 · 标题」，点击跳页；顶部显示本地目录状态
  （未生成 / 已就绪 / 内置目录副本 / 手动编辑 / 已过期 / 生成中 / 生成失败），并保留
  「启用目录参与阅读规划」开关（阅读规划使用**本地**目录）；
  - 只有 PDF 内置目录、或本地目录已过期时，勾选该开关会**先把内置目录保存为本地目录**再启用，
    不会出现"有内置目录却勾不上"；这种副本显示为「内置目录副本」（区别于用户编辑保存的「手动编辑」）；
  - 启用后的具体作用见下面「4.1 启用目录参与阅读规划的含义」。
- **编辑 / 手动**：对**当前展示的目录**生效（内置目录也能编辑）。编辑会打开逐行表格：
  改页码/标题、删除行、添加行，保存后写成**本地目录**并自动切到本地页签；
  「＋ 手动」从零录入；
- **目录生成…**：生成入口是按钮，点开是一个**弹窗**，包含两种方式：
  1. **按目录页生成**：填书前印刷目录页范围（`3`、`3,4`、`3-5`）→「识别目录页」→
     预览（条目、页码偏移、置信度、罗马页码单独偏移、警告）→「用这些条目生成本地目录」；
     设置后显示「目录页 3、4」徽标，可一键清除；
  2. **按标题规则生成**：扫描全文章节标题/字号规则生成本地目录（不需要目录页；
     会清除目录页设置后重新生成）。
  弹窗支持 Esc 关闭、点遮罩关闭。

目录列表直接铺在面板里；面板底部保留「图表与公式」节点入口；
大文档（>80 页）生成时显示进度。

## 3. 识别规则（本机纯函数，不调模型）

代码：`packages/core/src/toc-pages.ts`。

### 3.1 目录页 → 条目

- 只读用户指定的目录页，排除跨页重复的页眉/页脚与「目录 / Contents」标题行；
- 每行拆「标题 + 印刷页码」：`第1章 导论 ........ 12`、`2.1 抽样方法 ....... 45`；
- 为减少误判，无引导点的行要求**页码靠右（右边界 > 0.8）**或标题以章节编号开头
  （`第X章`、`2.1`、`一、`、`Chapter 3`…）；页码 > 2000 视为年份/正文数字，不当作页码；
- **折行标题**：标题占一行、页码在下一行（或标题折成多行后页码在末尾）时，会把各行拼回一条；
  只有标题没有页码的行不会被当成条目，并在预览里如实提示；
- **页码单独一行**：`第三章 结论` 一行、`60` 一行时配对成条目；
- **双栏目录**：文本层把同一视觉行挤成「标题A …… 12 标题B …… 34」时，按引导点逐条拆开
  （`parseTocLineEntries` 返回多条），不会只取最后一个页码；
- **罗马数字页码**：识别 `i/ii/iii/xii…`，保留标签原文（`printedPageLabel`），内部换算成序号
  （i=1、ii=2…），并单独估计它到物理页码的偏移；
- 层级取标题编号深度：`2.1` → 2，`第三章`/`Chapter 3` → 1，`一、` → 2，无编号 → 1。

### 3.2 印刷页码 → PDF 物理页码

书前有版权页/序言时，印刷第 1 页通常不等于 PDF 第 1 页。实现用正文标题块投票估计偏移：

1. 取正文（排除目录页）识别出的标题块；
2. 每个目录条目按归一化标题（去编号/标点/空格）与标题块匹配；
3. 每对匹配得到一个 `物理页 - 印刷页`，取票数最多的偏移；
4. **阿拉伯数字页码**与**罗马数字页码**分成两组分别投票（前言 i/ii 与正文 1/2 是两套页码）；
5. 预览显示两组偏移与置信度；置信度低时给出「建议核对」警告；页码按
   `印刷页 + 该组偏移` 映射，超出文献页数的条目跳过并计数。

### 3.3 手动增删改

- 目录面板「编辑 / ＋ 手动」支持**编辑 / 手动添加 / 删除 / 保存**：
  - 当前展示 PDF 内置目录时也可以编辑，保存后写成**本地目录**并自动切到本地页签；
  - 当前展示本地目录时直接编辑它；
- 保存后状态为「手动编辑」（`NavigationStatus.manual=true`、`build_state='manual'`），
  仍会写入当前 `sourceHash`：换文件 / 改无关区域 / 改目录页设置后照样变 `stale`，
  提示重新生成；重新生成会覆盖手动修改（面板上有提示）；
- 手动目录与自动生成目录是同一份数据（`doc_navigation`），阅读规划与目录跳转都用它。

### 3.4 默认行为不变

- 没设置目录页：仍按 PDF 书签（有的话）或标题规则生成（`navigationNodes`）；
- 设置了目录页：**只信目录页**；若目录页解析不出任何条目，生成会失败并报错，不会静默退回
  标题规则（避免用户以为用了目录页、实际是猜的）；
- 目录页设置进入导航 `sourceHash`：改目录页范围会让旧目录变成 `stale`，提示重新生成。

## 4. 接口与数据

- `POST /api/v1/documents/:id/navigation/toc-preview`，body `{ toc_pages: number[] }`
  → 返回 `TocNavigationPreview`：`entries`（title / printedPage / printedPageLabel / pageKind / level / raw）、
  `nodes`、`stats`（entries / offset / offsetConfidence / romanEntries / romanOffset /
  romanOffsetConfidence / nodes / skipped）、`warnings`。**不保存**。
- `POST /api/v1/documents/:id/navigation`，body 可带 `toc_pages` → 保存设置并生成目录；
  `toc_pages: []` 表示清除设置、回到标题规则；
- `GET /documents/:id/navigation/status`（`NavigationStatus`）新增 `toc_pages`、`manual` 字段；
- 手动编辑目录：`POST /documents/:id/navigation/entries`（整份节点一次性保存，支持增删改）；
- 目录页设置持久化在本地 SQLite 表 `doc_navigation_toc(document_id, pages)`；
- API 客户端：`api.previewTocNavigation(documentId, tocPages)`、`api.buildNavigation(documentId, { tocPages })`。

### 4.1 「启用目录参与阅读规划」的含义

本地目录（`doc_navigation`）只有 `ready + enabled` 时才参与规划；它**只影响“读哪些页”**，
不是原文证据，不进入回答内容或引用：

1. **章节选择（读哪一章）**：`GET /documents/:id/chapters` 与聊天里的“读第几章”优先用本地目录分章
   （`chaptersFromLocalNavigation`）；未启用/过期时回退结构树（PDF 书签/标题规则），即旧行为；
   `DocumentChapters.source` 会说明用的是 `navigation` 还是 `structure`；
2. **局部阅读范围**：命中页扩展到“所在章节”时，结构树结果与本地目录章节**取并集**
   （`expandRequestedPages` / local plan）；目录接错最多多读几页，不会少读；
3. **回读/补读**：模型按章节标题请求补读时，用启用的目录把章节标题映射成页码范围；
4. **缺口/反面补读照旧**：覆盖台账、逐字证据核验、反面迹象页补读、继续阅读都不受目录开关影响；
5. **关掉即回退**：状态不是 `ready` 或未启用时，以上全部回退到结构树/旧行为。

## 5. 已知限制

1. **页码偏移**是统计估计：置信度低时会提示核对；目录页本身不进入目录条目；
2. **罗马数字页码**已支持（i/ii/iii…），但与正文标题完全对不上时会按「i=第1页」原样映射并提示；
3. **双栏目录**：同一视觉行被文本层拼成一行时已能按引导点拆条；如果文本层把标题和页码拆到
   完全不同的行/列（读序错乱），仍可能错配，可只选单栏或用无关区域遮住另一栏；
4. **图表目录/插图目录**：没有「标题 + 页码」格式的行会被忽略；只有标题没有页码的行也会忽略并提示；
5. 目录页设置只影响导航生成，不改变阅读正文索引、检索与证据口径；
6. 手动编辑的目录在「重新生成」时会被覆盖（面板有提示）；如需保留请先备份/截图。
