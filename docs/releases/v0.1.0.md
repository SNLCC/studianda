## 概要

勘读 Studianda 0.1.0，首个 Windows 桌面版本：把 PDF 精读、可回原文的问答、翻译、批注、笔记与本地检索放在同一个窗口里，资料默认保存在你选择的本地目录。

主要内容：

- PDF 导入、目录与结构识别、参考文献与页下注；
- 阅读伙伴按页/按章/整篇精读，回答带可点击回原文的引用；
- 独立问答、本机全文检索与语义近似；
- 高亮、下划线、区域框选与批注，文献笔记与独立笔记；
- 本页/整篇/选文翻译，逐段保存；
- 数据备份与资料位置迁移。

## 下载

- **Windows x64 安装包**：`Studianda-Setup-0.1.0.exe`（本 Release 资产）
- `latest.yml`、`SHA256SUMS.txt`、`build-manifest.json` 也随 Release 提供，供应用内更新与校验使用。

> 当前只发布 Windows 版本，尚未对 macOS 打包与实测。

## 安装与覆盖安装

1. 下载 `Studianda-Setup-0.1.0.exe` 并运行；
2. 安装向导可修改安装目录（per-user 安装，默认不需要管理员权限）；
3. 首次启动选择资料文件夹；之后文献、笔记、数据库都保存在这里；
4. **覆盖安装/应用内更新只替换程序目录，不影响资料目录**；卸载程序默认也不删除资料。

如果之前装过旧版本，直接运行新安装包覆盖安装即可；也可以让应用内更新完成下载与安装。

## 已知问题：未签名

- 本版本**未做代码签名**。Windows SmartScreen 可能提示「未知发布者」或「Windows 已保护你的电脑」；
  点击「更多信息 → 仍要运行」即可继续安装。
- 应用内更新会通过 HTTPS 从 GitHub 下载并用 `latest.yml` 中的 sha512 校验安装包完整性，
  但这不等于代码签名，无法证明发布者身份；请只从本仓库的 Releases 页面下载。

## 校验安装包

下载后可以核对 SHA256：

```powershell
Get-FileHash .\Studianda-Setup-0.1.0.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
# 两行 hash 应一致（SHA256SUMS.txt 为小写；比较时忽略大小写）
```

`latest.yml` 中的 `sha512` 是安装包的 SHA-512 base64 摘要，主要由 electron-updater 自动校验。
