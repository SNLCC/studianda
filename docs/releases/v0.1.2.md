## 摘要

勘读 Studianda `0.1.2`：以**许可证切换**为主的一次维护版本。项目自身代码由 PolyForm Noncommercial 1.0.0 改为 **Apache License 2.0**；同时补齐第三方许可证据、把安装器里的 WinShell 调用替换为本项目脚本实现，并让安装包只包含 Windows x64 所需的原生二进制。

## 主要变更

### 许可

- 项目自身代码改为 **Apache License 2.0**（见仓库根目录 `LICENSE`、`NOTICE`）：可以自由使用、修改与再分发（含商业用途），需保留版权与许可声明以及 NOTICE 中的归属信息；这是 OSI 认可的开源许可证。
- `0.1.1-test.1` 及更早版本仍按 PolyForm Noncommercial 1.0.0 发布。
- 随包第三方组件、内置字体、PDF.js 资源、安装器插件与 Electron 运行时**不受** Apache-2.0 约束，仍按各自许可证分发；清单与兼容性说明见 `legal/THIRD-PARTY.md` 与 `legal/COMPATIBILITY.md`。
- 安装向导的许可页与安装包内 `resources/LICENSE`、`resources/NOTICE`、`resources/legal/` 已同步更新。

### 许可证据与安装器

- 补齐 expat / selectors 的许可原文、MPL-2.0 组件源码归档、libjpeg-turbo（IJG）署名、字体版权行与 OFL 文档、`nsis7z.dll` 来源与哈希、Electron 随包运行时 DLL 的来源说明。
- 安装器不再内嵌 WinShell（上游只有 "Freeware" 标注、无许可文本的第三方插件）；快捷方式的 AppUserModelID 改由安装脚本调用 Windows 公开 API 写入，行为不变。
- 安装包只包含 Windows x64 所需的 `@napi-rs/canvas` 原生二进制。

### 数据与兼容

- 应用数据格式与 `0.1.1-test.1` 相同，可直接覆盖安装；资料目录不受影响。
- 安装包仍未做代码签名，首次运行 Windows 可能提示「未知发布者」，属预期行为。

## 下载

- Windows x64 安装包：`Studianda-Setup-0.1.2.exe`
- 安装包校验值见 `SHA256SUMS.txt`；应用内更新读取 `latest.yml`。
