## 摘要

勘读 Studianda 0.1.1 是 0.1.0 之后的修复与体验更新：兼容从上一版本资料目录迁移、收紧首次使用的须知确认、整理设置页布局，并补齐安装包内的法律文件。

## 主要变化

- **修复旧数据迁移**：从旧 Python 版资料目录或上一版本资料目录迁移时，PDF 按 `documents.path`、`papers/<sha256>.pdf`、`papers/<文档 ID>.pdf`、资料目录根部 `<文档 ID>.pdf` 依次查找；文档被跳过时不再产生指向不存在文献的孤儿译文/页面编辑数据，补上 PDF 后可重跑迁移补齐。
- **首次使用确认**：欢迎页需先打开当前版本《使用须知与隐私说明》，勾选「已查看使用须知与隐私说明」并确认已满 18 周岁后，才能开始使用；须知版本升级会重新要求确认。
- **欢迎页与设置页布局**：欢迎页压缩为紧凑布局，在 1024×600 及以上视口完整显示且不溢出；修复「启动后自动检查更新」复选框换行、Embedding/Rerank 两栏错位、使用须知在设置中重复出现等问题；诊断与维护改为可折叠分组。
- **法律文件**：使用须知版本更新为 v1.10；安装包与源码仓库各自携带完整的许可与声明文件（LICENSE、NOTICE、`legal/`、安装许可提示、完整版使用须知）；移除暂不需要的 CLA 文件。

## 下载

- **Windows x64 安装包**：`Studianda-Setup-0.1.1.exe`（本 Release 资产）
- `latest.yml`、`SHA256SUMS.txt`、`build-manifest.json` 也随 Release 提供，供应用内更新与校验使用。

> 当前只发布 Windows 版本，尚未对 macOS 打包与实测。

## 安装与覆盖安装

1. 下载 `Studianda-Setup-0.1.1.exe` 并运行；
2. 安装向导可修改安装目录（per-user 安装，默认不需要管理员权限）；
3. 首次启动选择资料文件夹；之后文献、笔记、数据库都保存在这里；
4. **覆盖安装 / 应用内更新只替换程序目录，不影响资料目录**；卸载程序默认也不删除资料。

如果之前装过旧版本，直接运行新安装包覆盖安装即可；也可以让应用内更新完成下载与安装。

## 已知问题：未签名

- 本版本**未做代码签名**。Windows SmartScreen 可能提示「未知发布者」或「Windows 已保护你的电脑」；
  点击「更多信息 → 仍要运行」即可继续安装。
- 应用内更新会通过 HTTPS 从 GitHub 下载并用 `latest.yml` 中的 sha512 校验安装包完整性，
  但这不等于代码签名，无法证明发布者身份；请只从本仓库的 Releases 页面下载。

## 校验安装包

下载后可以核对 SHA256：

```powershell
Get-FileHash .\Studianda-Setup-0.1.1.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
# 两行 hash 应一致（SHA256SUMS.txt 为小写；比较时忽略大小写）
```

`latest.yml` 中的 `sha512` 是安装包的 SHA-512 base64 摘要，主要由 electron-updater 自动校验。
