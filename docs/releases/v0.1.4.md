## 这是测试版

勘读 Studianda `0.1.4` 是**测试版**：功能与本地数据格式都还在调整，可能出错，也可能在后续版本里变化。

- 重要文献的原始 PDF 请自己另存一份，不要只留在应用里。
- 想多一层保险，可以在「设置 → 数据与维护」里做一次数据备份。
- 欢迎试用和反馈，但请按测试版预期对待它。

## 下载哪个文件

到本页下方 **Assets** 里，**只需要下载一个**：

- **`Studianda-Setup-0.1.4.exe`** —— Windows x64 安装包。双击运行，按向导安装。

> 只发布 Windows 版本；macOS 尚未打包与实测。

## 安装前必读

1. **安装包未签名**：Windows 可能提示「Windows 已保护你的电脑」或「未知发布者」。点「更多信息 → 仍要运行」即可继续，这是预期行为，不是文件损坏。
2. **首次启动先选资料目录**：文献副本、笔记、数据库都存在这个目录里；之后可以在设置里更换，但卸载程序不会删除它。
3. **先读使用须知**：启动页要先打开并勾选确认《使用须知与隐私说明》，同时确认已年满 18 周岁，之后才能开始使用。
4. **不内置模型和密钥**：本工具不自带任何 AI 模型、也不含任何平台密钥。导入、阅读、批注、笔记、检索等本地功能装好就能用；对话、翻译、摘要、语音等需要你在「设置 → 模型服务」里填入自己的 Key。
5. **从旧版本升级**：直接运行新安装包覆盖安装即可，只替换程序目录，资料目录不受影响。
