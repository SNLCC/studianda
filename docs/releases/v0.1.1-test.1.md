## 摘要

勘读 Studianda `0.1.1-test.1`：Windows 桌面版的测试构建，基于 `0.1.0` 之后的一批修复，重点改善朗读播放、独立笔记管理，以及 Markdown 笔记导入的可靠性与重复导入提示。

> 这是预发布测试版，主要用于测试者手工安装验证；不会通过应用内自动更新推送给普通用户。

## 本测试版主要变更

### 朗读

- **修复朗读没有声音**：渲染进程 CSP 缺少 `media-src blob:`，导致本地生成的语音音频被浏览器拦截；已放行 `blob:` 音频，并为窗口启用 `autoplayPolicy: no-user-gesture-required`，使异步生成后的朗读可以正常播放。
- 播放失败不再静默：音频为空、格式不支持或被拦截时会明确提示原因，便于反馈。

### 独立笔记

- **手动排序与分类**：笔记列表支持拖拽排序（持久化），也可拖到文件夹或在「移动到…」下拉里选择目标文件夹。
- **重命名**：列表项或编辑区可重命名笔记，实际修改正文第一行并保留原有 `#` 标题层级。
- **编辑区充分利用屏幕空间**：笔记工作区改为填满可用高度，左右两列各自滚动，Markdown/富文本编辑区不再受固定高度限制。
- **笔记导航栏收起/展开**：可收起左侧笔记本列表，状态会记住；窄窗口下为覆盖式抽屉。
- **批量操作**：支持多选笔记后批量移入回收站、批量移动到文件夹。

### 文件夹

- **修复删除文件夹提示「文件夹不存在」**：Markdown 导入产生的文件夹现在会登记为真实文件夹，可正常重命名、删除和移动。
- 删除文件夹语义调整：文件夹内笔记移动到上一级/根目录，子文件夹上移一级，不再因「文件夹非空」拒绝删除。

### Markdown 笔记导入

- **附件重名不再丢失**：解析顺序改为笔记同目录 → 资料库根相对路径 → 唯一文件名匹配 → 多候选按最近路径选择并给出警告；原笔记软件里真实存在的同名附件不再因无法判定而跳过。
- **重复导入提示**：导入前会检查选中文件是否此前已导入过，按「资料库路径 + 相对路径」识别（同名文件不会混淆）；可选择「更新已存在」或「跳过已存在」，导入报告会列出跳过数量。
- 导入时同步登记文件夹层级。

### 数据与兼容

- 资料库数据库自动升级到 schema 19（笔记手动排序），升级前会先做迁移前备份；升级不影响文献、笔记、批注与译文内容。
- 已装 `0.1.0` 的测试者可直接覆盖安装本测试版；资料目录不受影响。

## 下载

- **Windows x64 安装包**：`Studianda-Setup-0.1.1-test.1.exe`（本 Release 资产）
- `latest.yml`、`SHA256SUMS.txt`、`build-manifest.json` 随 Release 提供，供校验使用。

> 当前只发布 Windows 版本，尚未对 macOS 打包与实测。

## 安装与覆盖安装

1. 下载 `Studianda-Setup-0.1.1-test.1.exe` 并运行；
2. 安装向导可修改安装目录（per-user 安装，默认不需要管理员权限）；
3. 首次启动选择资料文件夹；之后文献、笔记、数据库都保存在这里；
4. **覆盖安装只替换程序目录，不影响资料目录**；卸载程序默认也不删除资料。

如果之前装过 `0.1.0`，直接运行新安装包覆盖安装即可。

## 已知问题

- **未做代码签名**：Windows SmartScreen 可能提示「未知发布者」或「Windows 已保护你的电脑」；点击「更多信息 → 仍要运行」即可继续。
- 这是预发布测试版：GitHub 上会标记为 pre-release，应用内自动更新默认不会推送到它；测试者需要手动下载安装。
- 反馈问题时请注明版本 `0.1.1-test.1`、Windows 版本、复现步骤与截图；如方便可附「设置 → 诊断与维护 → 导出诊断包」（不含 PDF 正文与密钥）。

## 校验安装包

下载后可以核对 SHA256：

```powershell
Get-FileHash .\Studianda-Setup-0.1.1-test.1.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
# 两行 hash 应一致（SHA256SUMS.txt 为小写；比较时忽略大小写）
```

`latest.yml` 中的 `sha512` 是安装包的 SHA-512 base64 摘要，主要由 electron-updater 自动校验。
