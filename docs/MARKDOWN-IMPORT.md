# Markdown 笔记导入：实现与数据边界

本文件说明「勘读 Studianda」的 Markdown 笔记导入功能的实现方式、用户数据边界和第三方组件原则。本文不构成法律意见；商业发行前建议进行正式知识产权审查。

## 实现方式

- 导入器只读取用户选择的本地目录中的 **Markdown、图片和附件文件**，不读取、不修改、不复制其他笔记应用的代码、插件、主题、图标或字体资源。
- Markdown、wikilink、callout 等按公开的文本写法/文件格式解析；解析、转换与重写逻辑全部为本仓库独立实现。
- 界面、对话框、文件树、进度条与提示文案均为本项目原创，不使用任何第三方应用的 Logo、品牌图标、界面截图或主题样式。
- 附件在导入后的笔记中只使用本项目自己的纯文本标签与资源 URL，不使用第三方应用的媒体图标或图标库。

## 用户数据

- 导入操作只处理用户有权访问的本地文件；不绕过任何访问控制或 DRM。
- 导入后的笔记存于勘读自己的数据目录（SQLite + note-assets），不写回原笔记目录。
- 不收集、不上传导入的笔记内容；除用户明确选择的服务外，导入过程不联网。

## 用户告知

- 导入界面提示：请仅导入用户拥有合法权利或已获授权的本地笔记与附件；导入内容仅保存在本机，不会上传到 Studianda 服务器；因导入内容产生的第三方权利、保密或伦理责任由导入者承担。
- 若导入内容包含个人信息、伦理审查材料、涉密科研数据或第三方作品，用户应自行确认其有权处理，并遵守适用的个人信息保护、保密和科研伦理要求。
- 本地数据目录未内置多用户权限隔离；敏感数据场景应由用户自行采取磁盘加密、系统账户隔离等措施。
- 首次启动的资料位置页、欢迎引导页与主界面侧栏同时提示：本机数据与备份未加密，敏感资料需自行加密磁盘或隔离账户；导入时另提示须拥有合法权利。

## 第三方组件

- 当前导入器没有引入额外的 Markdown 解析库，也没有复制任何第三方笔记应用的代码或资源。
- 如需为 Mermaid 等语法增加渲染依赖：只选择 MIT/Apache-2.0 等兼容许可证的独立库，并在 `legal/THIRD-PARTY.md`、`legal/inventory.json`、`NOTICE` 中登记版本与许可证；不复用任何第三方应用的渲染器代码或图标。
