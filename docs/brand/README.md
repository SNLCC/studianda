# 品牌图标（勘读 Studianda）

## 两张图、两个时机

| 时机 | 图形 | 载体 |
|---|---|---|
| 安装包 / 卸载程序（还没装到本机的东西） | **叠书版**：三本叠放的书 + S 形朱红书签 | `apps/desktop/build/icon.ico`、`icon.png` |
| 安装后的 exe / 桌面快捷方式 / 开始菜单（未运行） | **叠书版**：与安装包同一张图 | `apps/desktop/build/icon.ico`（electron-builder `win.icon`） |
| 打开之后的窗口与系统任务栏、应用内品牌位 | **开卷版**：打开的书 + S 形朱红书签 | `apps/desktop/build/icon-open.ico`（`BrowserWindow.icon`，主窗口与译文窗口）、`icon-open.png`（其它平台兜底）、`packages/ui/src/brand-mark-data.ts`（界面内标记/首次启动页） |

两张图都经过同一套处理：青瓷深底、宣纸色书本、朱红 S 书签、轻 3D（投影、页厚、书脊内阴影、顶部高光），
并且 **图案的 alpha 包围盒严格居中于 512 设计网格**（生成脚本在合成时自动居中）。

## 图形要点

- **叠书版**：三本奶油色书本叠放；封面为**青瓷布面**——**左侧是一条弯曲的书脊边**（沿书本左端圆弧包过去，不是一整块色板；有外缘受光、内侧折缝阴影、头/尾包角与极浅书脊棱），**右侧是书口**（向内凹的弧形页缘 + **长短错落、向书内部渐隐的横纹页线**），从剪影和纹理都能分辨书脊与书口；朱红书签从最上面一本垂下，渐细、尾部渐淡、燕尾收尾。
- **开卷版**：两片纸页 + 书脊 + 页厚（页缘线），书脊处有内阴影，上缘有高光；书签从书脊升起，S 形、渐细、尾部渐淡，顶端与书上缘严格齐平。
- S 形对应英文名 **Studianda** 的首字母；开卷/书签对应中文名「勘读」的读书与落款。

## 居中

- 生成脚本先画透明底图形层，再把整层放大 **1.32×**（让图案占满更多图标面积），
  取「实心轮廓」（alpha > 240，排除柔和投影）的包围盒，将其中心平移到 `(256, 256)` 后合成到青瓷底上；
- 因此两版图标在 512 网格上是严格居中的，下采样到 16–256 也保持居中；
- 应用内标记直接使用同一张开卷图的 256 px 版本，不额外裁切或缩放偏移。

## 使用规则

- 桌面程序名称/窗口标题/任务栏名称显示为 **勘读Studianda**；安装后的桌面与开始菜单快捷方式名称为 **勘读Studianda**；
- 应用内品牌位（左侧栏顶部）显示 **勘读·Studianda**，下方保留副标题「本地 · 学术空间」，图标使用开卷版；
- 最小尺寸 16 px；图标按 16/24/32/48/64/128/256 逐级栅格化，不要只拿 1024 缩放替代；
- 保持圆角方形轮廓，不拉伸、不旋转；阴影/高光已内置，不要在外面再加投影或描边；
- 深色与浅色任务栏都可直接使用（青瓷深底 + 纸色书本）。

## 生成

```bash
python scripts/generate-icon.py
```

需要 Pillow。脚本以 2048 px 超采样后按尺寸下采样，输出叠书版 ICO/PNG、开卷版 ICO/窗口图标与 `docs/brand` 预览，
并把开卷版 256 px 写为 `packages/ui/src/brand-mark-data.ts`（供界面内标记与首次启动页使用）。
