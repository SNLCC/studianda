# 名称档案：勘读 / Studianda

> 本文件记录项目中英文名称的造词、含义、读音与写法。名称与图标的归属许可见
> [`legal/BRAND.md`](../../legal/BRAND.md)；图标设计见 [`docs/brand/README.md`](README.md)。

## 一、中文名「勘读」

- **读音**：kān dú（勘，阴平；读，阳平）。
- **字义**：
  - **勘**：校勘、勘校、勘误——逐字比对、考查文字与版本的工夫；
  - **读**：阅读、解读。
  - 合起来是「一边读、一边校勘核对」的阅读方式，直接对应产品「精读 + 逐段核对 + 引用可回原文」的核心动作。
- **定位**：中文市场的产品主名；两字、易写易记、有学术质感。
- **写法**：写作「勘读」，不额外加「空间」「阅读」「笔记」等后缀；带后缀的写法不再使用。

## 二、英文名「Studianda」

### 1. 构词拆解

| 成分 | 来源 | 含义 |
|---|---|---|
| 词干 `studi-` | 拉丁语 *studium*（研习、钻研）／*studia*（研习之事，复数） | 与 study、studio 同源，指向「研习」 |
| 词尾 `-anda` | 拉丁语动形词（gerundive）中性复数词尾 **-anda** | 「应当被……的事物」的集合，如 agenda / memoranda / corrigenda |

**合起来：studianda = 「应当被研习的诸事」**，即「有待研习之事」。

### 2. 词源与构词法说明

- 英语里以 `-anda` 结尾的常用词都出自同一构词法：**agenda**（待办之事）、**memoranda**（待记之事）、
  **corrigenda**（待勘误之事）、**addenda**（待补之事）、**propaganda**（待传布之事）——都是拉丁动形词的中性复数。
- 因此 `-anda` 本身就在向读者提示「复数、被动、应当被做」：不是「正在研习」，而是「值得／有待被研习的一组事物」。
- 需如实说明的一点：古典拉丁中 *studere*（研习）的动形词是 *studendus / -a / -um*，中性复数写作 **studenda**；
  **studianda** 属**新拉丁（科学拉丁）**用法——由 *studium* 派生的动词 *studiare* 给出 *studiandus / -a / -um*，
  中性复数即 *studianda*（植物学等拉丁文里可见 *studiandae* 的用例）。
- 结论：**Studianda 是「可解释的新拉丁式生造词」**——含义清楚、构词有据，但不是古典拉丁的标准拼法；对外解释时应说明这一点，不宣称它是古典拉丁。

### 3. 含义

- 直译：「应当被研习的事物」；中文习惯表达为「**有待研习之事**」。
- 与产品定位的关系：产品不替你「读完」，而是把值得研习的材料、证据与出处摆在你面前，由你来判断——
  对应本地优先、用户主导、引用可回溯的产品气质。

### 4. 读音

- 英语近似音标：**/ˌstuː.diˈæn.də/**，重音在第三个音节 **AN**。
- 中文近似：**斯图迪安达**。
- 注意：不是「studio-anda」（斯图迪奥安达）；开头的 studi- 与 studio 同源，但不按 studio 断词。

### 5. 写法规范

| 场景 | 写法 |
|---|---|
| 正文、标题、品牌位 | **Studianda**（首字母大写，其余小写，一词连写，不加连字符） |
| 代码标识 | 包名 `studianda`；`appId: com.studianda.app`；可执行文件 `Studianda.exe` |
| 与中文名并列 | 勘读（Studianda） |
| 避免 | `StudiAnda`、`Studianda-app`、「Studianda 空间」等带后缀写法 |

## 三、两个名字的关系

- 中英文**不是直译关系**，而是同一项目的两个名字：
  - 中文「勘读」指向**动作**（怎么读：边读边校）；
  - 英文 Studianda 指向**对象**（读什么：有待研习之事）。
- 分工：中文名负责中文市场与界面；英文名负责代码标识、安装包、仓库与国际识别。
- 副标题／品类说明：「本地 · 学术空间」「本地学术空间」。

## 四、名称在代码与发布物中的落点

- 界面与文档：中文「勘读」（窗口标题、首次启动页、译文窗口、安装器快捷方式、许可提示等）；
- 代码与发布物：英文 Studianda（`appId: com.studianda.app`、`productName: Studianda`、
  `Studianda.exe`、userData `%APPDATA%\Studianda`）；
- 仓库／包名：`studianda`。
